Create a PAT in about 1 minuteNo account-wide access needed
Open GitHub token page ↗
  1. 1Enter a token name such as repo2drawio and choose a short expiration.
  2. 2Set Resource owner to the repository owner. For an organization repo, choose that organization—not your personal account.
  3. 3Under Repository access, choose Only select repositories and select the repo you want to analyze.
  4. 4Under Repository permissions, set only Contents → Read-only, then click Generate token.
  5. 5Copy the new github_pat_… value and paste it below. Organization approval may be required.
Then click Generate diagram ↑

The token is used once to read selected repository files and is never stored. Revoke it in GitHub after a one-off analysis.
